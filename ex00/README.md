# Personal Portfolio - Exercise 00

## Description
An authentic, responsive personal portfolio website built entirely from scratch using HTML5, CSS3, and JavaScript ES6+, adhering strictly to 42 School requirements without any external templates, frameworks, or UI libraries.

## Features
- Semantic HTML5 structure.
- Responsive design using CSS Flexbox and Media Queries.
- Interactive Theme Switcher (Dark/Light mode) powered by JavaScript.
- Sections covering About Me, Skills, Project Showcase (Projects 00-03), Hobbies, and Contact Form.

## How to Run
Simply open `index.html` in any modern web browser or run it via a local development server.
